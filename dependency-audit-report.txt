A. SAFE OR STRONG REMOVAL CANDIDATES
------------------------------------
These are recommendations only. They must pass the verification steps before removal.

1. Alphacloud.MessagePack.AspNetCore.Formatters 4.1.0
   Location: swas.UI\swas.UI.csproj
   Evidence: No MessagePack formatter or package API usage was found in application source.
   Security relevance: Introduces MessagePack 2.5.108, which has advisories.
   Recommendation: Remove if no hidden serialization/configuration dependency exists.
   Impact: Could affect runtime serialization or SignalR/API behavior.
   Verification: Search configuration/startup/deployment files and test serialization and SignalR functionality.

2. ClosedXML 0.105.0
   Location: swas.UI\swas.UI.csproj
   Evidence: No ClosedXML or XLWorkbook usage was found.
   Recommendation: Remove if no Excel/reporting feature uses it indirectly.
   Impact: Could break Excel export if used through reflection or external code.
   Verification: Search all source/configuration files and test all reporting/export features.

3. DotNetEnv 3.2.0
   Location: swas.UI\swas.UI.csproj
   Evidence: Only using DotNetEnv directives were found. No Env.Load or equivalent API was found.
   Recommendation: Remove after verifying that .env files are not used by deployment scripts.
   Impact: Could affect hidden environment bootstrap logic.
   Verification: Search for .env files, Env.Load calls, startup scripts, and deployment documentation.

4. Grpc.Core 2.46.6
   Locations: swas.UI, swas.DAL, swas.BAL
   Evidence: Grpc.Core appears as using directives only; no gRPC APIs or .proto files were found.
   Recommendation: Remove or consolidate after runtime-loading verification.
   Impact: Could break hidden plugin/reflection-based gRPC code.
   Verification: Search all files, deployment scripts, reflection loading, and production configuration.

5. Swashbuckle.AspNetCore 6.5.0
   Location: swas.UI\swas.UI.csproj
   Evidence: No AddSwaggerGen, UseSwagger, UseSwaggerUI, or Swagger configuration was found.
   Recommendation: Remove if Swagger is not a deployment requirement.
   Impact: Swagger documentation/UI would no longer be available.
   Verification: Confirm /swagger is not used by operations, testing, monitoring, or deployment.

6. Microsoft.VisualStudio.Web.CodeGeneration.Design 9.0.0
   Location: swas.UI\swas.UI.csproj
   Evidence: Development/scaffolding package; no runtime usage found.
   Recommendation: Remove if scaffolding is no longer part of development workflow.
   Impact: Visual Studio scaffolding may stop working.
   Verification: Confirm team development procedures do not require scaffolding.

7. Explicit Microsoft.AspNetCore.Antiforgery 2.3.11
   Location: swas.UI\swas.UI.csproj
   Evidence: Antiforgery is actively used, but the explicit package is much older than the .NET 9 target and ASP.NET Core shared framework supplies this feature.
   Recommendation: Investigate removing the explicit reference rather than removing antiforgery functionality.
   Impact: Form validation behavior could change if the old package is overriding framework assets.
   Verification: Test all MVC and Razor Pages POST forms, login, registration, and authorization flows.
